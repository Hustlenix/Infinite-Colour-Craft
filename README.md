# 🎨 Infinite Colour Craft

> *"With great color mixing comes great responsibility..."* — Friendly Neighborhood Color Alchemist 🕸️

Hey there, true believer! Welcome to **Infinite Colour Craft** — an alchemy-style color crafting workspace and 2D canvas painting studio built right in your browser.

Combine primitive pigments, discover hundreds of unique shades, craft custom palettes, complete daily canvas quests, and paint your masterpiece using studio-grade brushes!

---

## 🚀 What's Inside the Lab?

- **🧪 Infinite Color Alchemist**: Start with Red, Yellow, Blue, White, and Black. Drag and mix them on your workspace to discover secret pigments (from *Electric Cyan* to *Cosmic Nebula*).
- **🖌️ Pro 2D Painting Studio**:
  - **Dynamic Brushes**: Smooth Wet Bristle, Fine Pen, Translucent Marker, Spray Can, Chisel Ribbon, and Wet Smudge Blender.
  - **StreamLine Stabilizer**: Smooth out shaky hand strokes like a pro web-slinger.
  - **Speed & Velocity Dynamics**: Fast strokes taper naturally while slow strokes lay down thick paint.
  - **Blend Modes & Canvas Flips**: Multiply, Screen, Overlay, Color Dodge, plus Instant Horizontal & Vertical canvas mirroring (`H` / `V`).
  - **Symmetry & Stencil Guide**: Mirror drawing and outline stencils.
- **📜 Color Recipe Book & Quests**: Track all discovered colors, recipes, and unlock achievements.
- **📅 Daily Color Challenges**: New color target every single day with reward bonuses.
- **🔊 WebAudio Synthesizer**: Satisfying physical paint sounds and harmonic audio feedback while brushing and mixing.
- **🥚 Secret Easter Egg**: Tap the top-left logo 5 times in quick succession if you dare... 😉

## 🕹️ Quick Shortcuts

| Key | Action |
| --- | --- |
| `B` / `P` / `M` / `S` | Brush / Pen / Marker / Spray |
| `C` / `U` | Chisel Ribbon / Wet Smudge |
| `R` / `G` | Rainbow Brush / Emoji Stamp |
| `F` / `I` / `E` | Bucket Fill / Eyedropper / Eraser |
| `H` / `V` | Flip Canvas Horizontally / Vertically |
| `X` | Quick-swap Brush & Eraser |
| `[` / `]` | Adjust Brush Size |
| `Ctrl + Z` / `Ctrl + Y` | Undo / Redo |

## 🛠️ Local Setup & Running

Got Node.js installed? Fire up your local terminal and spin up the app in seconds:

```bash
# 1. Clone the repo
git clone https://github.com/Hustlenix/Infinite-Colour-Craft.git

# 2. Jump into the folder
cd Infinite-Colour-Craft

# 3. Install dependencies
npm install

# 4. Start the dev server
npm run dev
```

Open your browser at `http://localhost:3000` and start crafting!
