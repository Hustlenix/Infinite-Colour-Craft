Infinite Colour Craft

"With great color mixing comes great responsibility..." That's what my uncle, the Friendly Neighborhood Color Alchemist, tells me every time I open this thing. 🕸️

Welcome to Infinite Colour Craft, an alchemy-style color mixing playground and 2D canvas painting studio built right in your browser.

Combine primitive pigments to create new ones, discover shades you didn't know existed, build out your own palettes, chase the daily quests, and put it all to use painting on the canvas.

What's inside

Start with five primitive pigments, Red, Yellow, Blue, White, and Black, and drag them together to see what happens. Mix long enough and you'll stumble on secret colors, everything from Electric Cyan to Cosmic Nebula.

The painting side has real depth too. There are six brushes (Smooth Wet Bristle, Fine Pen, Translucent Marker, Spray Can, Chisel Ribbon, and Wet Smudge Blender), a stroke stabilizer for shaky hands, and dynamics that respond to speed, so fast strokes taper off naturally and slow ones lay down thicker paint. You've got blend modes too (Multiply, Screen, Overlay, Color Dodge), instant canvas flipping with H and V, and a symmetry and stencil mode for mirrored drawing or tracing outlines.

Every color you discover gets logged in a recipe book, with achievements for hitting certain milestones, plus a new color target each day and bonus rewards if you land it. If you're painting with the sound on, you'll hear paint sounds and some harmonic feedback while you mix and brush.

There's also an easter egg. Tap the logo in the top left five times fast if you're curious. 😉

Quick shortcuts
Key	Action
B / P / M / S	Brush / Pen / Marker / Spray
C / U	Chisel Ribbon / Wet Smudge
R / G	Rainbow Brush / Emoji Stamp
F / I / E	Bucket Fill / Eyedropper / Eraser
H / V	Flip Canvas Horizontally / Vertically
X	Quick-swap Brush & Eraser
[ / ]	Adjust Brush Size
Ctrl + Z / Ctrl + Y	Undo / Redo

How I made this

This was just a fun little browser project. I got the idea from neal.fun/infinite-craft, though that game mixes random real-world objects into new ones just because it's fun, while this one mixes color pigments into new shades and actually gives you somewhere to use them: a full canvas to paint on.
